# home-seeker

Proyecto personal de investigación inmobiliaria.

El objetivo es estudiar, durante aproximadamente el próximo año, dónde podría comprar una vivienda para vivir.

De momento se basa en Markdown y archivos sencillos. Se irá construyendo paso a paso.

Cada anuncio interesante se guarda en `anuncios/` siguiendo [docs/plantilla-anuncio.md](docs/plantilla-anuncio.md).
